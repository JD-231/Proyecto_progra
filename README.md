# Asistente Inteligente con NLP

## Descripción
Este proyecto es una aplicación web desarrollada con Flask que utiliza modelos de Procesamiento de Lenguaje Natural (NLP) para realizar tareas como:

- Corrección ortográfica
- Análisis de sentimientos
- Resumen de textos
- Traducción automática
- Detección de idioma
- Respuesta a preguntas

Los datos de entrada y salida se almacenan en MongoDB.

## Tecnologías utilizadas
- Python
- Flask
- Transformers (Hugging Face)
- MongoDB
- HTML, CSS y JavaScript

## Instalación

1. Clona el repositorio:

```bash
git clone https://github.com/JD-231/Proyecto_progra.git
```

2. Instala las dependencias:

```bash
pip install flask transformers pymongo spellchecker
```

3. Ejecuta la aplicación:

```bash
python app.py
```
